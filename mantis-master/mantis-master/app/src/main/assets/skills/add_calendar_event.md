# Skill: Add Calendar Event

## Trigger
add event, create event, schedule, calendar, meeting, appointment, book, add to calendar, remind me on

## Steps
1. Open the Calendar app (Google Calendar or Samsung Calendar) from the home screen or app drawer.
2. Tap the "+" or "New event" / "Create" button — usually bottom-right corner or a colored circle.
3. Tap the event title field and type the event name.
4. Tap the start date field and set the correct date using the date picker.
5. Tap the start time field and set the correct start time.
6. Tap the end time field and set the correct end time (or duration).
7. If the user specified a location, tap the location field and type it.
8. If the user specified a description or notes, tap the description field and type it.
9. If the user wants a reminder/notification, tap "Add notification" and set the lead time (e.g. 15 minutes before).
10. Tap "Save" or the checkmark to confirm the event.
11. Verify the event appears on the calendar on the correct date, then call complete.

## Notes
- Google Calendar: "+" button is in the bottom-right corner; event creation has a compact quick-entry and a full "More options" form.
- Samsung Calendar: tap a date cell to start creating an event for that date.
- All-day events: if the user says "all day", toggle the "All day" switch; time pickers will disappear.
- If the task does not specify an end time, set it to 1 hour after the start time by default.
- Recurring events: look for a "Repeat" or "Does not repeat" dropdown; tap it to set frequency.
