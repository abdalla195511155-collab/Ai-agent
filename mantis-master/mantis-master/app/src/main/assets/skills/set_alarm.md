# Skill: Set Alarm

## Trigger
set alarm, wake me up, alarm for, remind me at, morning alarm

## Steps
1. Open the Clock app from the home screen or app drawer.
2. Tap the "Alarm" tab at the bottom of the screen (if not already selected).
3. Tap the "+" or "Add alarm" button to create a new alarm.
4. Set the hour: tap the hour field or the hour on the time picker and adjust to the correct value.
5. Set the minutes: tap the minute field or the minute on the time picker and adjust.
6. Set AM or PM if shown — tap the correct label.
7. If a label/name field is available and the user specified one, tap it and type the label.
8. If repeat days are needed (e.g. "every weekday"), tap the day chips to select the correct days.
9. Tap "Save" or the checkmark to confirm the alarm.
10. Verify the new alarm appears in the alarm list with the correct time and is toggled ON.
11. Call complete.

## Notes
- Samsung Clock uses a circular dial picker by default; you can also switch to keyboard input by tapping the keyboard icon.
- If the user says "7:30 AM tomorrow" with no repeat, leave repeat as "Never" (default).
- The alarm toggle must be ON (blue) after saving — if it is OFF, tap it to enable it.
- If an alarm for the same time already exists, toggle it on rather than creating a duplicate.
