# Skill: Send Message

## Trigger
send message, text, whatsapp, sms, message someone, chat, dm, write to, contact

## Steps
1. Open the messaging app (WhatsApp, Samsung Messages, Telegram, etc.) from the home screen or app drawer.
2. Look for a compose / new message button — usually a pencil icon or "+" in the bottom-right corner. Tap it.
3. In the recipient field, type the contact name or phone number.
4. Tap the correct contact from the autocomplete suggestions that appear.
5. Tap the message text field (usually at the bottom of the screen).
6. Type the message text using the type action.
7. Tap the Send button — usually an arrow or paper-plane icon to the right of the text field.
8. Confirm the message appears in the conversation thread, then call complete.

## Notes
- If already inside a conversation with the correct contact, skip steps 2–4 and go directly to step 5.
- WhatsApp: compose button is a green circle with a pencil icon, bottom-right.
- Samsung Messages: compose button is a blue pencil icon, bottom-right.
- If the keyboard does not appear after tapping the text field, tap the field again.
- Do NOT call complete until the message is visibly sent (appears in the thread with a sent/delivered indicator).
- For group chats, select the group name in step 4 instead of an individual contact.
