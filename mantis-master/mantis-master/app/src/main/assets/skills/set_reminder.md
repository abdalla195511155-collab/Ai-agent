# Skill: Set Reminder

## Trigger
remind me, set a reminder, reminder for, don't let me forget, notify me, remember to

## Steps
1. Open the Clock app or a dedicated Reminders app (Google Keep, Samsung Reminder, or Google Assistant reminders).
2. For Clock app: tap the "Reminder" tab if available, then tap "+" to add a new reminder.
3. For Samsung Reminder: tap "+" and enter the reminder title and time.
4. For Google Keep: tap the "+" to create a new note, enter the text, then tap the bell icon to set a reminder time.
5. Type the reminder text / title describing what the user wants to be reminded of.
6. Set the reminder date — tap the date field and choose the correct date.
7. Set the reminder time — tap the time field and set the correct time.
8. Tap "Save" or the checkmark to confirm.
9. Verify the reminder appears in the list with the correct time and text, then call complete.

## Notes
- On Samsung devices, "Reminder" is a built-in app accessible from the home screen or app drawer.
- Google Assistant reminders can also be set, but require typing into the assistant interface.
- If the user says "in 30 minutes" or a relative time, calculate the absolute time from now before entering it.
- Do not confuse "reminder" with "alarm" — alarms make sound; reminders are notification-based.
- If the reminder app is not available, fall back to creating a Calendar event at the specified time with a notification.
