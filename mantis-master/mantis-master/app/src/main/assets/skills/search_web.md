# Skill: Search Web

## Trigger
search for, look up, google, find online, what is, who is, how to, browse, open website, go to website, search the internet

## Steps
1. Open Chrome (or the default browser) from the home screen or app drawer.
2. Tap the address bar / URL bar at the top of the browser.
3. Clear any existing text in the address bar if present (long-press → Select All → Delete, or tap the X button).
4. Type the search query or URL.
5. Tap the "Go" / Enter button on the keyboard or press the search key.
6. Wait for the search results or page to load.
7. If the task is to open a specific website, verify the correct page has loaded.
8. If the task is to find specific information, locate it on the results page.
9. Call complete once the search is done or the page is open.

## Notes
- If Chrome is not installed, look for Samsung Internet or Firefox in the app drawer.
- Tapping the address bar on Chrome may show recent searches — if the query matches a suggestion, tap it instead of typing.
- For URLs, include "https://" only if typing a full domain; for searches, just type keywords.
- If the page does not load (network error), do not retry indefinitely — call stuck with the reason.
