# Skill: Open App

## Trigger
open, launch, start, go to, navigate to, switch to, find app

## Steps
1. Press the Home button to make sure you are on the launcher/home screen.
2. Look at the UI elements on screen. If you can see the target app icon, tap it directly.
3. If the app is not visible, swipe up from the bottom of the screen to open the app drawer.
4. Scan the app list for the target app name. Tap it if visible.
5. If still not found, tap the search bar at the top of the app drawer and type the app name.
6. Tap the matching result to launch the app.
7. Wait for the app's main screen to load — the package name in the snapshot will change.
8. Once the app is open and its UI is visible, call complete.

## Notes
- On Samsung OneUI, the app drawer opens by swiping up on the home screen.
- If you tapped an icon and the UI did not change after 2 steps, the tap likely missed — try a slightly different coordinate.
- Some apps take 2–3 seconds to fully load; wait for the package name to change before acting.
- If the app is already open in the background, pressing its icon from the home screen brings it to the foreground.
