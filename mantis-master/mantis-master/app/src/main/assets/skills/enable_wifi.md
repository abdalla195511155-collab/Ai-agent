# Skill: Enable WiFi / Connect to Network

## Trigger
wifi, wi-fi, connect to wifi, turn on wifi, enable wifi, join network, internet, wireless, connect to network, disconnect wifi, forget network

## Steps
1. Pull down the notification shade by swiping down from the top of the screen twice.
2. Look for the WiFi tile in the Quick Settings panel. If WiFi is OFF (gray), tap it once to turn it ON.
3. To connect to a specific network, long-press the WiFi tile — this opens the full WiFi settings screen.
4. On the WiFi settings screen, the list of available networks will appear. Tap the target network name.
5. If the network requires a password, a dialog will appear — tap the password field and type the password.
6. Tap "Connect" or "Join".
7. Wait for the device to connect — the network will show "Connected" below its name.
8. Call complete once connected (or once WiFi is simply enabled, if no specific network was requested).

## Notes
- If the WiFi tile is not visible in Quick Settings, swipe the Quick Settings panel left to find it.
- Turning WiFi ON via the tile does not connect to a specific network — it will auto-connect to remembered networks.
- To connect to a new network (not previously joined), use steps 3–7.
- If a network asks for a password and none was provided by the user, call stuck with reason "WiFi password required".
- To turn WiFi OFF: tap the WiFi tile in Quick Settings once to toggle it off (it will turn gray).
- On Samsung OneUI, long-pressing a Quick Settings tile opens its full settings page reliably.
